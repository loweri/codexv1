## 🇧🇷 Português

O **Compendium: Codex do Engenheiro** é uma aplicação web interativa de gamificação de carreira desenhada para acompanhar visualmente a progressão de conhecimentos e habilidades práticas em **Engenharia de Dados**.

### ✨ Principais Funcionalidades

- **Árvore de Habilidades Interativa (SVG + Canvas):** Navegação por categorias com renderização vetorial dinâmica de nós e conexões de pré-requisito.
- **Duplo Sistema de Moedas (XP & KP):**
  - **XP (Experience Points):** Mede a aplicação prática em projetos reais.
  - **KP (Knowledge Points):** Mede o domínio teórico e conceitual.
- **8 Categorias Principais de Engenharia:**
  1. **Fundamentos** (Lógica, Algoritmos, Estruturas de Dados)
  2. **Programação** (Python, POO, Pandas, APIs, Logging)
  3. **Banco de Dados** (SQL, Modelagem, Índices, PostgreSQL)
  4. **Engenharia de Dados** (ETL, Data Warehouse, Data Lake, Orquestração)
  5. **Cloud** (AWS, S3, IAM, Supabase, BigQuery)
  6. **DevOps** (Git, GitHub, CI/CD, Linux, Docker)
  7. **Visualização** (Dashboards, KPIs, Power BI, Metabase)
  8. **Soft Skills** (Comunicação, Documentação, Resolução de Problemas)
- **Nós BOSS:** Marcos principais da jornada de aprendizado representando projetos práticos end-to-end.
- **Persistência & Backup:** Salvamento automático via `localStorage`, com suporte a importação e exportação de estado em JSON.

<a name="english"></a>
## 🇺🇸 English

The **Compendium: Engineer's Codex** is an interactive web application for career gamification, designed to visually track skill progression and practical knowledge in **Data Engineering**.

### ✨ Key Features

- **Interactive Skill Tree (SVG + Canvas):** Category-based navigation with dynamic vector rendering of skill nodes and dependency lines.
- **Dual Currency System (XP & KP):**
  - **XP (Experience Points):** Measures hands-on project application.
  - **KP (Knowledge Points):** Measures theoretical concept mastery.
- **8 Core Data Engineering Categories:**
  1. **Fundamentals** (Logic, Algorithms, Data Structures)
  2. **Programming** (Python, OOP, Pandas, APIs, Logging)
  3. **Databases** (SQL, Modeling, Indexes, PostgreSQL)
  4. **Data Engineering** (ETL, Data Warehouse, Data Lake, Orchestration)
  5. **Cloud** (AWS, S3, IAM, Supabase, BigQuery)
  6. **DevOps** (Git, GitHub, CI/CD, Linux, Docker)
  7. **Visualization** (Dashboards, KPIs, Power BI, Metabase)
  8. **Soft Skills** (Communication, Documentation, Problem Solving)
- **BOSS Nodes:** Key milestones representing end-to-end practical projects.
- **Persistence & Backup:** Automatic state saving via `localStorage`, featuring JSON import and export capability.
